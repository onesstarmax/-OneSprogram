🐍 Learn Python

Learn Python step by step with simple examples.

Variables

Variables are used to store information that a program can use later. 

name = "John"
age = 20

print(name)
print(age)

If Statements

An if statement allows Python to make decisions based on a condition. 

age = 18

if age >= 18:
    print("You are an adult")
else:
    print("You are under 18")

Loops

Loops allow you to repeat instructions. 

for number in range(1, 6):
    print(number)

Functions

Functions are reusable blocks of code. 

def greet(name):
    print("Hello " + name)

greet("John")

🌐 Learn JavaScript

Learn JavaScript with simple notes and examples.

Variables

Variables store information. 

let name = "John";
let age = 20;

console.log(name);
console.log(age);

If Statement

An if statement allows JavaScript to make decisions. 

let age = 20;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Under 18");
}

For Loop

A loop repeats a block of code. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Functions

A function is a reusable block of code. 

function greet(name) {
    console.log("Hello " + name);
}

greet("John");

🔵 Learn C

Learn C programming with simple examples.

Hello World

C programs commonly use printf() to display output. 

#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");

    return 0;
}

Variables

Variables store values such as integers, characters and decimal numbers. 

#include <stdio.h>

int main(void)
{
    int age = 20;
    float height = 1.75;

    printf("Age: %d\n", age);
    printf("Height: %.2f\n", height);

    return 0;
}

If Statement

The if statement allows a C program to make decisions. 

#include <stdio.h>

int main(void)
{
    int age = 20;

    if (age >= 18)
    {
        printf("Adult\n");
    }
    else
    {
        printf("Under 18\n");
    }

    return 0;
}

For Loop

A for loop repeats a block of code. 

#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}

Functions

Functions organize code into reusable blocks. 

#include <stdio.h>

void greet()
{
    printf("Hello from C!\n");
}

int main(void)
{
    greet();

    return 0;
}

➕ Learn C++

Learn C++ with simple notes and examples.

Introduction to C++

C++ is a general-purpose programming language developed by Bjarne Stroustrup.

It supports procedural, object-oriented and generic programming.

Hello World

C++ commonly uses iostream and std::cout to display output. 

#include <iostream>

int main()
{
    std::cout << "Hello, world!\n";

    return 0;
}
Variables

Variables store information that a program can use later. 

#include <iostream>

int main()
{
    int age = 20;
    double height = 1.75;

    std::cout << age << "\n";
    std::cout << height << "\n";

    return 0;
}
Data Types

C++ supports different types of data. 

int age = 20;
float height = 1.75f;
double price = 99.99;
char grade = 'A';
bool student = true;
If Statement

An if statement allows a program to make decisions. 

#include <iostream>

int main()
{
    int age = 20;

    if (age >= 18)
    {
        std::cout << "Adult";
    }
    else
    {
        std::cout << "Under 18";
    }

    return 0;
}
Loops

Loops allow a program to repeat instructions. 

#include <iostream>

int main()
{
    for (int i = 1; i <= 5; i++)
    {
        std::cout << i << "\n";
    }

    return 0;
}
Functions

Functions organize programs into reusable blocks of code. 

#include <iostream>

void greet()
{
    std::cout << "Hello from C++!";
}

int main()
{
    greet();

    return 0;
}
Classes and Objects

Classes can be used to create objects containing data and functions. 

#include <iostream>
#include <string>

class Student
{
public:
    std::string name;
};

int main()
{
    Student student;

    student.name = "John";

    std::cout << student.name;

    return 0;
}
Inheritance

Inheritance allows one class to derive features from another class. 

class Animal
{
public:

    void eat()
    {
        std::cout << "Eating";
    }
};

class Dog : public Animal
{
};
Templates

Templates allow C++ to support generic programming. 

template <typename T>

T add(T a, T b)
{
    return a + b;
}
