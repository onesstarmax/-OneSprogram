Learn C programming with simple notes and examples.

Hello World

📝 Note: C programs commonly use printf() to display output. 

#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}

Variables

📝 Note: Variables store values such as integers, characters and decimal numbers. 

#include <stdio.h>

int main(void)
{
    int age = 20;
    float height = 1.75;

    printf("Age: %d\n", age);
    printf("Height: %.2f\n", height);

    return 0;
}

If Statement

📝 Note: The if statement allows a C program to make decisions based on a condition. 

#include <stdio.h>

int main(void)
{
    int age = 20;

    if (age >= 18)
    {
        printf("Adult\n");
    }
    else
    {
        printf("Under 18\n");

    return 0;

For Loop

int main(void)

C++

A high-level, general-purpose programming language used for systems, games, applications and high-performance software.

Learn C++

➕ Learn C++

Learn C++ with simple notes, explanations and examples.

Introduction to C++

Note: C++ is a high-level, general-purpose programming language created by Danish computer scientist Bjarne Stroustrup.

C++ was first released in 1985 as an extension of the C programming language.

History of C++

Note: Development of C++ began in 1979 when Bjarne Stroustrup worked on a language called "C with Classes".

The name C++ refers to C's increment operator ++.

Hello World

Note: C++ commonly uses iostream and std::cout to display output. 

#include <iostream>

int main()
{
    std::cout << "Hello, world!\n";

    return 0;
}
Variables

Note: Variables store information that a program can use later. 

#include <iostream>

int main()
{
    int age = 20;
    double height = 1.75;

    std::cout << age << "\n";
    std::cout << height << "\n";

    return 0;
}
Data Types

Note: C++ supports different types of data, including integers, floating-point numbers, characters and Boolean values. 

int age = 20;
float height = 1.75f;
double price = 99.99;
char grade = 'A';
bool student = true;
If Statement

Note: An if statement allows a C++ program to make decisions. 

#include <iostream>

int main()
{
    int age = 20;

    if (age >= 18)
    {
        std::cout << "Adult";
    }
    else
    {
        std::cout << "Under 18";
    }

    return 0;
}
Loops

Note: Loops allow a program to repeat instructions. 

#include <iostream>

int main()
{
    for (int i = 1; i <= 5; i++)
    {
        std::cout << i << "\n";
    }

    return 0;
}
Functions

Note: Functions organize a program into reusable blocks of code. 

#include <iostream>

void greet()
{
    std::cout << "Hello from C++!";
}

int main()
{
    greet();

    return 0;
}
Classes and Objects

Note: C++ supports object-oriented programming. Classes can be used to create objects that contain data and functions. 

#include <iostream>

class Student
{
public:
    std::string name;
};

int main()
{
    Student student;

    student.name = "John";

    std::cout << student.name;

    return 0;
}
Inheritance

Note: Inheritance allows one class to derive features from another class. 

class Animal
{
public:
    void eat()
    {
        std::cout << "Eating";
    }
};

class Dog : public Animal
{
};
Templates

Note: C++ supports generic programming through templates. 

template <typename T>

T add(T a, T b)
{
    return a + b;
}
Standard Library

Note: The C++ Standard Library provides facilities such as containers, algorithms, strings, input/output and memory management. 

#include <vector>

std::vector<int> numbers = {
    1, 2, 3, 4, 5
};
C++ Standards

Note: C++ has been standardized through versions including C++98, C++03, C++11, C++14, C++17, C++20 and C++23.

The material you provided identifies ISO/IEC 14882:2024 as the C++23 standard.
